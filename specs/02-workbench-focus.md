# Workbench Focus

## JTBD

As a user, I need the concept map to remain central so I can examine source-derived material and reshape it into a representation that matches my understanding.

## Topic

The workbench prioritizes graph review on desktop screens.

## Phase

Phase 1.

## Acceptance Criteria

- The graph occupies the primary workspace on desktop-sized screens.
- Graph-relevant actions are easy to reach during review.
- Context for the current graph or selected element is visible without leaving the workbench.
- Secondary areas do not distract from graph review before agent work is active.
- The user can load, review, inspect, navigate, adjust, or save layout from the main workbench experience.
- The first release feels like a focused concept-map workbench rather than a general project dashboard.
- The workbench supports one working graph representation rather than asking users to manage multiple competing views.

## Non-Goals

- Mobile layout is not required for the current release.
- Collaboration surfaces are not required for the current release.
- Multiple graph representations are not required for the current release.
- A polished design system is not required for the current release.
