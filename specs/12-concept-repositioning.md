# Concept Repositioning

## JTBD

As a user, I need to adjust graph placement directly so I can make dense areas easier to understand.

## Topic

Users reposition concepts intentionally.

## Phase

Phase 2.

## Acceptance Criteria

- Users can move a concept to a new visible position when repositioning is active.
- Moving a concept updates the display promptly.
- Moving a concept does not change its meaning.
- Moving a concept does not change relationship meaning.
- Moved positions remain stable during the current review session.
- Moved positions can reappear after reload when layout saving is available.
- Repositioning works without accidental selection loss during normal use.
- Repositioning failures leave the previous valid graph available.

## Non-Goals

- Repositioning history is not required for the current release.
