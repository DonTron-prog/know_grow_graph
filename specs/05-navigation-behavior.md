# Navigation Behavior

## JTBD

As a user, I need to move around the graph smoothly so I can examine local detail without losing orientation.

## Topic

Users move around the graph canvas predictably.

## Phase

Phase 1.

## Acceptance Criteria

- Users can zoom into graph details.
- Users can zoom out to regain broader context.
- Users can pan to another region of the graph.
- Users can fit the graph into view when they need orientation.
- Navigation does not change graph content.
- Labels remain useful enough for review during normal navigation.
- Selection feedback remains understandable during normal navigation.
- Navigation gestures do not accidentally create, edit, or delete graph elements.

## Non-Goals

- Touch-first navigation is not required for the current release.
